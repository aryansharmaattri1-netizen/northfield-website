# OpenClaw Agency Website

High-conversion agency website built with Next.js, TypeScript, Tailwind CSS, and Framer Motion. Based on learnsales.us design patterns and incorporating OpenClaw brand identity, philosophy, service offerings, and content system.

## Features

✅ **Modern Tech Stack**
- Next.js 14 with App Router
- TypeScript for type safety
- Tailwind CSS for styling
- Framer Motion for animations
- Lucide React for icons

✅ **Complete Brand Identity**
- Brand philosophy & principles
- Service offerings (Ascend, Amplify, Atlas)
- Pricing tiers (Foundation, Scale, Pioneer)
- Content Operating System
- Intelligent outreach system

✅ **High-Conversion Design**
- Smooth scroll animations
- Gradient effects
- Responsive layout
- Premium UI components
- Performance optimized

## Getting Started

### Development
```bash
npm install
npm run dev
```

### Build & Deploy
```bash
npm run build
npm run start
```

### Deploy to Vercel
```bash
npm i -g vercel
vercel
```

## GitHub Deployment
```bash
git init
git add .
git commit -m "OpenClaw agency website"
git branch -M main
git remote add origin https://github.com/yourusername/openclaw-website
git push -u origin main
```
